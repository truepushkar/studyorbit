# StudyOrbit

## Platform
Native Android, built with Jetpack Compose. Core study workflows work offline without an account.

## Audience and purpose
Students can start a timed study session, control interruptions, schedule work, and review their time. The user selected starting a focus session quickly as the leading workflow.

## Constraints
Keep countdown, stopwatch, Pomodoro, optional strict mode, reminders, study history, access disclosures and device integrations. Use native touch targets and scalable text.
